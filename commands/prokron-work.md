# /prokron-work

Read `.prokron/README.md`, `STATE.md`, and `TASK_GRAPH.md`. Select the requested
task, or one ready task if none was named. If the requested work has no task yet,
create it first. Read that task and its governing ADRs, then inspect only the
specification and code needed for the task.

Mark it `WIP`, record the owner and claim date, and set `INTENT.md` to that one
task before implementation. As truth changes, update the task, graph, state, ADR
lineage, and journal rather than postponing all record keeping until session end.
