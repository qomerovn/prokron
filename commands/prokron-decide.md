# /prokron-decide

Use this workflow as soon as a material project choice is made, accepted, or
acted on; do not wait for `/prokron-decide` to be invoked. Append an ADR to
`.prokron/DECISIONS.md` with date, authority, context, decision, consequences,
affected tasks, and any `Supersedes` links. Never rewrite an earlier ADR,
including its original status. Update affected tasks, `TASK_GRAPH.md`, and
`STATE.md` when the decision changes project work.
