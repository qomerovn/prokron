# Prokron adapters

Adapters teach the current coding agent the model-agnostic adoption, sync and
resume protocol. The agent owns repository understanding, authority assessment,
uncertainty and human questions. Core owns schema, integrity, persistence and
continuity. No provider API or agent orchestration is required.

See the [generic protocol](generic/README.md), or copy the
[Codex](codex/AGENTS.md) / [Claude](claude/CLAUDE.md) instructions into the host's
instruction mechanism. Slash names below are workflow instructions, not commands
that the CLI automatically registers with a host.
